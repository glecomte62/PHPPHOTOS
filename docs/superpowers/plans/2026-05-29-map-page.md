# Map Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter une page carte interactive `/map.php` accessible depuis un menu de navigation sur toutes les pages, affichant toutes les photos géolocalisées du compte Flickr avec clustering et popup miniature.

**Architecture:** `FlickrAPI::getGeoPhotos()` interroge `flickr.photos.search` avec `has_geo=1` et pagine jusqu'à récupérer tous les marqueurs. `map-data.php` agrège, met en cache 1h dans `/tmp`, et expose un endpoint JSON. `map.php` charge Leaflet + markercluster, fetch le JSON, et rend la carte plein écran. Un menu `.site-nav` est ajouté dans tous les headers.

**Tech Stack:** PHP 8 / curl, Leaflet 1.9.4, Leaflet.markercluster 1.5.3, JS vanilla ES5, CSS custom properties existantes.

```php
/**
 * Retourne les photos géolocalisées de l'utilisateur (une page).
 * Retourne ['photos' => [...], 'pages' => N]
 * Chaque photo : ['id', 'title', 'lat', 'lng', 'url_thumb']
 */
public function getGeoPhotos(int $page = 1): array
{
    $data = $this->request([
        'method'   => 'flickr.photos.search',
        'user_id'  => $this->userId,
        'has_geo'  => 1,
        'extras'   => 'geo,url_z,url_m',
        'per_page' => 250,
        'page'     => $page,
    ]);

    if (($data['stat'] ?? '') !== 'ok') {
        throw new RuntimeException('Flickr API error: ' . ($data['message'] ?? 'unknown'));
    }

    $photos = [];
    foreach ($data['photos']['photo'] ?? [] as $p) {
        $lat = (float)($p['latitude']  ?? 0);
        $lng = (float)($p['longitude'] ?? 0);
        if ($lat === 0.0 && $lng === 0.0) continue;

        $photos[] = [
            'id'        => $p['id'],
            'title'     => $p['title'] ?? '',
            'lat'       => $lat,
            'lng'       => $lng,
            'url_thumb' => $p['url_z'] ?? $p['url_m'] ?? '',
        ];
    }

    return [
        'photos' => $photos,
        'pages'  => (int)($data['photos']['pages'] ?? 1),
    ];
}
```

## Task 2: map-data.php

**Files:**
- Create: `map-data.php`

- [ ] **Étape 1 : Créer `map-data.php`**

```php
<?php
require_once __DIR__ . '/config.php';
require_once __DIR__ . '/lib/FlickrAPI.php';

header('Content-Type: application/json; charset=utf-8');

$cacheFile = sys_get_temp_dir() . '/phpphotos_map_' . md5(FLICKR_USER_ID) . '.json';

// Cache valide (< 1h) → retour direct
if (file_exists($cacheFile) && (filemtime($cacheFile) + 3600) > time()) {
    readfile($cacheFile);
    exit;
}

$api    = new FlickrAPI(FLICKR_API_KEY, FLICKR_USER_ID);
$photos = [];

try {
    $page  = 1;
    $pages = 1;

    do {
        $result  = $api->getGeoPhotos($page);
        $photos  = array_merge($photos, $result['photos']);
        $pages   = $result['pages'];
        $page++;
    } while ($page <= $pages);

} catch (RuntimeException $e) {
    http_response_code(500);
    echo json_encode(['error' => $e->getMessage()]);
    exit;
}

$json = json_encode($photos, JSON_UNESCAPED_UNICODE);
file_put_contents($cacheFile, $json);
echo $json;
```

- [ ] **Étape 1 : Créer `map.php`**

```php
<?php
require_once __DIR__ . '/config.php';
?>
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Carte — Guillaume LECOMTE</title>
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;600;700&family=Inter:wght@300;400;500&display=swap" rel="stylesheet">
    <link rel="stylesheet" href="css/style.css">
    <link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css">
    <link rel="stylesheet" href="https://unpkg.com/leaflet.markercluster@1.5.3/dist/MarkerCluster.css">
    <link rel="stylesheet" href="https://unpkg.com/leaflet.markercluster@1.5.3/dist/MarkerCluster.Default.css">
</head>
<body>

<header class="site-header">
    <a class="site-title" href="index.php"><span class="site-title-first">Guillaume</span> <span class="site-title-last">LECOMTE</span></a>
    <nav class="site-nav">
        <a class="site-nav-link active" href="map.php">Carte</a>
    </nav>
</header>

<div id="map" class="map-fullscreen" data-user="<?= htmlspecialchars(FLICKR_USER_ID) ?>">
    <div class="map-loading" id="map-loading">Chargement de la carte…</div>
</div>

<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
<script src="https://unpkg.com/leaflet.markercluster@1.5.3/dist/leaflet.markercluster.js"></script>
<script>
(function () {
    'use strict';

    var mapEl   = document.getElementById('map');
    var loading = document.getElementById('map-loading');
    var userId  = mapEl.dataset.user;

    var map = L.map('map', { zoomControl: true }).setView([20, 0], 2);

    L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', {
        attribution: '© OpenStreetMap',
        maxZoom: 19,
    }).addTo(map);

    var markers = L.markerClusterGroup();

    fetch('map-data.php')
        .then(function (r) {
            if (!r.ok) throw new Error('Erreur serveur');
            return r.json();
        })
        .then(function (photos) {
            loading.style.display = 'none';

            photos.forEach(function (p) {
                var marker = L.circleMarker([p.lat, p.lng], {
                    radius:      7,
                    fillColor:   '#c8a96e',
                    color:       '#fff',
                    weight:      2,
                    opacity:     1,
                    fillOpacity: 0.9,
                });

                var thumb = p.url_thumb
                    ? '<img src="' + p.url_thumb + '" alt="' + escHtml(p.title) + '">'
                    : '';

                marker.bindPopup(
                    '<div class="map-popup">' +
                        thumb +
                        '<div class="map-popup-info">' +
                            '<p class="map-popup-title">' + escHtml(p.title || '—') + '</p>' +
                            '<a href="https://www.flickr.com/photos/' + escHtml(userId) + '/' + escHtml(p.id) + '" ' +
                               'target="_blank" rel="noopener">Voir sur Flickr →</a>' +
                        '</div>' +
                    '</div>',
                    { maxWidth: 220 }
                );

                markers.addLayer(marker);
            });

            map.addLayer(markers);
        })
        .catch(function (err) {
            loading.textContent = 'Impossible de charger les données carte.';
        });

    function escHtml(str) {
        return String(str)
            .replace(/&/g, '&amp;')
            .replace(/</g, '&lt;')
            .replace(/>/g, '&gt;')
            .replace(/"/g, '&quot;');
    }
})();
</script>
</body>
</html>
```
